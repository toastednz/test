# 🌟 Maths Fun! — Flashcards for Little Learners

A web-based maths flashcard game made for a 5-year-old new entrant. No
installation, no internet needed once loaded, no typing required — just big
colourful buttons.

## How to play

Open `index.html` in any browser (works great on a phone or tablet), then pick
a game:

- **🔢 Counting** — count the pictures and tap how many (1–10)
- **➕ Adding** — addition with picture hints (sums up to 10)
- **➖ Taking Away** — subtraction within 10, with crossed-out pictures
- **🎲 Mix It Up!** — a random mix of all three

Each round is 8 questions with three big answer buttons. A correct first try
earns a star ⭐, wrong answers just get a friendly "try again" — no penalties.
Stars add up across sessions (saved in the browser) and every finished round
ends in confetti.

## Notes for grown-ups

- Everything lives in the single `index.html` file — no build step, no
  dependencies, safe to open offline.
- Sounds are generated in the browser (little chimes for correct answers);
  they start after the first tap, as browsers require.
- To reset the star count, clear the site data for the page in your browser.
