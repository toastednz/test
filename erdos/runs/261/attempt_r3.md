STATUS: BLOCKED
## Result

Route 3 does not presently yield a proof of Q2. I proved that dyadic arithmetic cannot itself force termination: for every integer target \(r/2^j\) with \(1\le r\le j+1\), including every \(w(n)=n/2^n\), there is an explicit admissible infinite tail expansion that deliberately avoids termination. I also obtained an exact dual formulation of Q2 as a cofinite-representation problem starting from the fixed defect state \(2\), analyzed the initial greedy phase, and proved that the simplest attempted repair—an initial consecutive block followed by one isolated correction term—is arithmetically impossible. The remaining task is still to prove that at least one branch reaches zero, which is essentially the original reachability problem.

## Complete Argument

### 1. Residual formulation

Fix \(j\ge1\) and an integer \(r\) with
\[
0\le r\le j+2.
\]
We seek representations
\[
\frac r{2^j}=\sum_{k>j}\varepsilon_k\frac{k}{2^k},
\qquad \varepsilon_k\in\{0,1\}.
\]

Define
\[
r_j=r,\qquad
r_k=2r_{k-1}-k\varepsilon_k\quad(k>j).
\]
Inductively,
\[
\frac{r_k}{2^k}
=
\frac r{2^j}
-\sum_{\ell=j+1}^{k}\varepsilon_\ell\frac{\ell}{2^\ell}.
\tag{1}
\]

The total weight available after level \(k\) is
\[
\sum_{\ell>k}\frac{\ell}{2^\ell}=\frac{k+2}{2^k}.
\]
Consequently, any extendible path must satisfy
\[
0\le r_k\le k+2.
\tag{2}
\]

Conversely, if a digit sequence satisfies (2) for every \(k\), then
\[
0\le \frac{r_k}{2^k}\le \frac{k+2}{2^k}\longrightarrow0.
\]
Taking the limit in (1) proves
\[
\frac r{2^j}=\sum_{k>j}\varepsilon_k\frac{k}{2^k}.
\tag{3}
\]

The expansion is finite exactly when \(r_M=0\) for some \(M\), after which one takes every later digit to be zero.

For Q2, one starts at
\[
(j,r)=(n,n).
\]

### 2. Dyadic targets always have an explicit nonterminating expansion

This is the main obstruction to a naive Route 3 argument.

#### Proposition 1

For every \(j\ge1\) and every integer \(r\) with
\[
1\le r\le j+1,
\]
there exists an infinite subset \(A\subseteq\{j+1,j+2,\dots\}\) such that
\[
\frac r{2^j}=\sum_{a\in A}\frac a{2^a}.
\]
Moreover, the expansion is generated by an explicit deterministic rule and never reaches residual zero.

#### Proof

Starting from \(r_j=r\), suppose that the current level is \(k-1\) and
\[
1\le r_{k-1}\le k.
\]
Choose
\[
\varepsilon_k=
\begin{cases}
0,&2r_{k-1}\le k,\\
1,&2r_{k-1}>k.
\end{cases}
\tag{4}
\]

If \(2r_{k-1}\le k\), then
\[
r_k=2r_{k-1},
\]
so
\[
1\le r_k\le k.
\]

If \(2r_{k-1}>k\), then
\[
r_k=2r_{k-1}-k.
\]
This is positive, and because \(r_{k-1}\le k\),
\[
r_k\le k.
\]

Thus, inductively,
\[
1\le r_k\le k
\qquad(k>j).
\tag{5}
\]
In particular, the path never reaches zero, while (5) implies the admissibility bound (2). Equation (3) therefore gives an exact representation.

It remains to prove that the selected set is infinite. If \(\varepsilon_k=0\) for every sufficiently large \(k\), then the recurrence would eventually be
\[
r_k=2r_{k-1},
\]
so \(r_k\) would grow exponentially. This contradicts \(r_k\le k\). Hence infinitely many digits equal \(1\). ∎

Taking \(j=r=n\) gives:

#### Corollary 2

For every \(n\ge1\), \(w(n)\) has an explicit infinite representation using only indices larger than \(n\).

Thus dyadicness does not force all admissible expansions—or even the most natural “avoid overshoot” expansion—to terminate. A successful proof must distinguish and select a terminating branch.

### 3. The tail endpoint is a dyadic rational with no finite tail representation

The full tail total is
\[
\sum_{k>j}\frac{k}{2^k}=\frac{j+2}{2^j},
\]
which is dyadic.

If a subset \(A\subseteq\{j+1,j+2,\dots\}\) has this sum, positivity implies that no tail term may be omitted. Hence
\[
A=\{j+1,j+2,\dots\},
\]
which is infinite.

Therefore the statement

> every dyadic rational in a tail achievement interval has a finite tail representation

is false, at least at the upper endpoint. Any valid finite-termination theorem would have to exclude the endpoint and use quantitative distance from it.

For Q2, the scaled distance from the endpoint is always exactly \(2\):
\[
(j+2)-j=2.
\]

---

### 4. Exact defect duality

Define the defect from the full remaining tail by
\[
d_k=k+2-r_k.
\]
Let
\[
\eta_k=1-\varepsilon_k.
\]
Since
\[
d_{k-1}=k+1-r_{k-1},
\]
the residual recurrence gives
\[
\begin{aligned}
d_k
&=k+2-\bigl(2r_{k-1}-k\varepsilon_k\bigr)\\
&=2d_{k-1}-k(1-\varepsilon_k)\\
&=2d_{k-1}-k\eta_k.
\end{aligned}
\tag{6}
\]

Thus the defect obeys exactly the same recurrence as the residual, with complementary digits.

For Q2,
\[
r_n=n,
\qquad
d_n=n+2-n=2.
\tag{7}
\]

A finite representation terminates at level \(M\) exactly when
\[
r_M=0,
\]
which is equivalent to
\[
d_M=M+2.
\tag{8}
\]
Once the defect reaches \(M+2\), taking all later \(\eta_k=1\) keeps it at the upper boundary.

There is also a direct subset interpretation. If \(A\subseteq\{j+1,j+2,\dots\}\) is finite and
\[
\sum_{a\in A}w(a)=\frac r{2^j},
\]
then its complement \(B=\{k>j\}\setminus A\) is cofinite and
\[
\sum_{b\in B}w(b)
=
\frac{j+2-r}{2^j}
=
\frac{d_j}{2^j}.
\]
Conversely, the complement of any such cofinite representation gives a finite representation of \(r/2^j\).

Hence Q2 is equivalent to:

> For every \(n\), the dyadic number \(2^{1-n}\) has a cofinite representation using the strict tail \(k>n\).

Dynamically, this asks whether the state
\[
(n,2)
\]
can be driven to the upper boundary \(d_M=M+2\). This is exact, but not easier than driving \((n,n)\) to zero.

### 5. Branching is confined to a very narrow corridor

Consider a transition from level \(k-1\), with residual \(r\), to level \(k\). The two possible next states are
\[
2r,\qquad 2r-k.
\]

Both are locally admissible, meaning they lie in \([0,k+2]\), exactly when
\[
\frac{k}{2}\le r\le\frac{k+2}{2}.
\tag{9}
\]

For integer \(r\):

- if \(k\) is odd, the only branching state is
  \[
  r=\frac{k+1}{2};
  \]
- if \(k\) is even, the possible branching states are
  \[
  r=\frac k2,\qquad \frac k2+1.
  \]

A transition reaches zero only in the first even case:
\[
k\ \text{even},\qquad r=\frac k2,\qquad \varepsilon_k=1.
\tag{10}
\]

Thus termination is an exact midpoint-hitting problem. Interval coverage supplies an admissible continuation from every state, but usually does not supply two choices; the genuinely useful branching zone has width only \(1\).

### 6. The initial consecutive-block phase

Let
\[
n_m=2^{m+1}-m-2.
\]
Suppose that, starting from \(r_n=n\), one selects every one of
\[
n+1,n+2,\dots,n+m.
\]
Repeated use of the residual recurrence gives
\[
r_{n+m}=n+m+2-2^{m+1}=n-n_m.
\tag{11}
\]

This recovers the Borwein–Loring identity when \(n=n_m\).

The numbers \(n_m\) are strictly increasing because
\[
n_{m+1}-n_m=2^{m+1}-1.
\tag{12}
\]
Thus every \(n\ge1\) lies in a unique interval
\[
n_m\le n<n_{m+1}.
\]
Writing
\[
n=n_m+\delta,
\]
we have
\[
0\le\delta\le2^{m+1}-2,
\tag{13}
\]
and selecting the first \(m\) tail terms leaves residual \(\delta\) at level \(n+m\).

Under the ordinary greedy rule—select \(k\) whenever \(k\le2r_{k-1}\)—these are exactly the initially selected consecutive terms. If \(\delta=0\), the Borwein–Loring representation terminates. If \(\delta>0\), the next term is necessarily skipped.

This reduces the residual substantially in many cases, but not to a previously solved state family.

### 7. One isolated correction after the initial block is impossible

A tempting strengthening is to select
\[
n+1,\dots,n+m
\]
and then, after a gap, use one final term \(n+m+t\). The following shows that this never works when the gap is nonempty.

#### Proposition 3

There are no positive integers \(n,m\) and \(t\ge2\) satisfying
\[
\frac n{2^n}
=
\sum_{s=1}^{m}\frac{n+s}{2^{n+s}}
+
\frac{n+m+t}{2^{n+m+t}}.
\tag{14}
\]

#### Proof

Put
\[
P=2^{m+1},
\qquad
\delta=n+m+2-P.
\]
By (11), after selecting the first \(m\) terms the scaled residual is \(\delta\). Waiting \(t-1\) levels and then using the final term requires
\[
2^t\delta=n+m+t.
\tag{15}
\]
Since
\[
n=\delta+P-m-2,
\]
equation (15) becomes
\[
(2^t-1)\delta=P+t-2.
\tag{16}
\]

Let
\[
q=2^t-1.
\]
If (16) held, then
\[
q\mid 2^{m+1}+t-2.
\tag{17}
\]
Choose \(a\in\{0,\dots,t-1\}\) with
\[
a\equiv m+1\pmod t.
\]
Since \(2^t\equiv1\pmod q\),
\[
2^{m+1}\equiv2^a\pmod q.
\]
Therefore (17) would imply
\[
q\mid 2^a+t-2.
\tag{18}
\]

But
\[
0<2^a+t-2<2^t-1=q.
\]
For \(t=2\), the left side is at most \(2<3\); for \(t=3\), it is at most \(5<7\). For \(t\ge4\),
\[
2^a+t-2\le2^{t-1}+t-2<2^t-1.
\]
This contradicts (18). ∎

Thus, after missing a Borwein–Loring equality, termination cannot be achieved merely by skipping a run of terms and then taking one exact-fit term. Any successful route must involve at least one nonterminal subtraction after the initial block.

### 8. Finite truncations are arithmetically sparse

At horizon \(M=j+L\), the possible scaled finite subsums are
\[
\sum_{k=j+1}^{M}\varepsilon_k k2^{M-k}.
\]
There are at most \(2^L\) distinct such values, while their full numerical range has length
\[
\sum_{k=j+1}^{M}k2^{M-k}
=
(j+2)2^L-(M+2).
\tag{19}
\]

Thus finite subsums at a fixed horizon occupy at most about a fraction \(1/(j+2)\) of the available integer lattice points. The full interval theorem emerges only after closure over all horizons; it cannot be upgraded to finite exact coverage by a straightforward finite-level interval argument.

### 9. Ledger

**Proved**

1. Exact residual and defect recurrences.
2. Every target \(r/2^j\) with \(1\le r\le j+1\) has an explicit nonterminating tail expansion.
3. The upper tail endpoint is dyadic but has no finite tail representation.
4. Q2 is equivalent to reaching the upper boundary from defect state \(2\), or to a cofinite representation of \(2^{1-n}\).
5. Branching occurs only in the midpoint corridor (9).
6. Exact residual after an initial consecutive block.
7. No consecutive initial block can be repaired by one isolated later term after a nonempty gap.
8. Fixed-horizon finite subsums are too sparse for a direct interval-filling proof.

**Plausible but unproved**

1. The ordinary greedy algorithm may terminate for every starting state \((n,n)\). This would solve Q2 but appears substantially stronger than the original existence claim.
2. Every integer state \(1\le r\le j+1\) may have some terminating path. No descent argument establishing this was found.
3. The initial reduction \(n\mapsto \delta=n-n_m\) may form part of a multistage arithmetic funnel, but subsequent levels depend on both \(n\) and \(\delta\).

**Dead ends**

1. “Every dyadic point of a tail interval terminates”: false at the upper endpoint.
2. “Dyadicness forces an admissible expansion to terminate”: false by Proposition 1.
3. Finite-horizon interval filling: impossible by the counting estimate (19).
4. Initial consecutive block plus one isolated correction: impossible by Proposition 3.

## Self-Audit

1. **The nonterminating construction proves existence of an infinite expansion, not failure of finite representations.**  
   This distinction is essential. Proposition 1 is used only to rule out arguments that force every expansion to terminate; it gives no counterexample to Q2.

2. **The defect formulation may look like progress but is exactly dual to the original reachability problem.**  
   I do not claim it solves anything by itself. Its value is that every Q2 instance starts from the same residual value \(2\), but the level \(n\) remains nonautonomous.

3. **The obstruction in Proposition 3 applies only to a very restricted support pattern.**  
   It does not exclude representations with two or more later correction terms, sparse complicated supports, or non-greedy paths. The modular proof is complete for the stated pattern, but its scope is narrow.

```python
# Exact forward residual checker and ordinary greedy search.

def greedy_termination(n, horizon):
    """
    Ordinary greedy rule:
    select k iff its weight does not exceed the current residual,
    equivalently iff 2*r >= k.
    Returns the terminating level and selected indices, or None.
    """
    r = n
    selected = []
    for k in range(n + 1, horizon + 1):
        eps = int(2 * r >= k)
        if eps:
            selected.append(k)
        r = 2 * r - k * eps
        assert 0 <= r <= k + 2
        if r == 0:
            return k, selected
    return None


def exact_check(n, A):
    assert len(A) == len(set(A))
    M = max([n] + list(A))
    lhs = n << (M - n)
    rhs = sum(a << (M - a) for a in A)
    return lhs == rhs
```

```python
# The explicit nonterminating policy from Proposition 1.

def avoid_zero_path(j, r, horizon):
    """
    Requires 1 <= r <= j+1.
    At equality 2*r == k, deliberately skip k rather than terminate.
    """
    assert 1 <= r <= j + 1
    digits = []
    for k in range(j + 1, horizon + 1):
        eps = int(2 * r > k)
        r = 2 * r - k * eps
        assert 1 <= r <= k
        digits.append(eps)
    return r, digits
```

```python
# Backward dynamic program:
# states at level n that can terminate by a fixed horizon H.

def terminating_states(n, H):
    good = {0}  # residuals at level H
    for k in range(H, n, -1):
        prev = set()
        for s in good:
            # epsilon_k = 0: s = 2*r
            if s % 2 == 0:
                r = s // 2
                if 0 <= r <= k + 1:
                    prev.add(r)

            # epsilon_k = 1: s = 2*r - k
            if (s + k) % 2 == 0:
                r = (s + k) // 2
                if 0 <= r <= k + 1:
                    prev.add(r)
        good = prev
    return good


def verify_q2_up_to(N, H):
    failures = []
    for n in range(2, N + 1):
        if n not in terminating_states(n, H):
            failures.append(n)
    return failures
```

## Route Diagnosis

The tail interval theorem works perfectly for existence of an arbitrary expansion but loses precisely the information Q2 needs: whether a path hits the exact midpoint state required for termination. Proposition 1 shows that even dyadic targets always admit a branch that avoids zero forever, so termination cannot follow from rationality, integrality, compactness, or interval coverage alone.

The strongest concrete funnel found was the initial consecutive block, which reduces \(n\) to \(n-n_m\). However, the next simplest repair is impossible by a Mersenne-modulus obstruction, and no monotone invariant or contraction survives subsequent nonterminal selections. At that point Route 3 reduces to the original nonautonomous reachability assertion and is therefore BLOCKED.

A fresh attempt should focus on one of two sharper questions:

- prove universal termination of the ordinary greedy recurrence
  \[
  r_k=
  \begin{cases}
  2r_{k-1},&2r_{k-1}<k,\\
  2r_{k-1}-k,&2r_{k-1}\ge k,
  \end{cases}
  \]
  starting from \(r_n=n\); or
- use backward computation to identify a genuine parametrized family of midpoint-return maps with at least two correction terms after the initial block.

Any proposed finite-termination theorem should first survive the endpoint counterexample, the explicit zero-avoiding path, and the one-correction obstruction proved above.
