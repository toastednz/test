## Result

I did not solve Erdős Problem #197 or prove all ternary-shell instances satisfiable. I obtained an exact reduction of each shell orientation problem from \(M(M-1)\) independent progression choices to \(M^{2}/3\) binary “arithmetic-line phase” choices, identified all orientations forced immediately by incoming edges, and proved that these forced orientations are consistent and acyclic. I also found explicit obstructions to the most natural cycle-descent arguments: phase-consistent directed cycles can use different common differences and collapse under division by \(3\), while a natural quotient-parity orientation satisfying every local incoming requirement already has a directed \(3\)-cycle in \(I_3=[27,80]\). Thus Route 2 is blocked precisely at controlling directed cycles of length at least \(3\) involving several common differences and residue classes.

## Complete Argument

### 1. Orientation formulation and cycle clauses

Fix \(k\geq 1\), put \(M=3^k\), and write
\[
X=[M,3M-1].
\]
For every internal progression
\[
T_{b,d}=(b-d,b,b+d),
\qquad
M+d\leq b\leq 3M-1-d,
\]
let \(s_{b,d}\in\{0,1\}\), with

- \(s_{b,d}=1\): \(b\) is a source, adding
  \[
  b\to b-d,\qquad b\to b+d;
  \]
- \(s_{b,d}=0\): \(b\) is a sink, adding
  \[
  b-d\to b,\qquad b+d\to b.
  \]

Add all fixed incoming arcs
\[
z\to y\qquad\text{whenever }x=2y-z\in U_k.
\]

The shell is satisfiable if and only if the resulting directed graph is acyclic for some choice of all \(s_{b,d}\). Indeed, a valid shell order induces one of the two states at each midpoint, and all arcs point forward. Conversely, a topological order of an acyclic orientation satisfies every incoming precedence and places each midpoint before both endpoints or after both.

This also gives an exact cycle-clause formulation. A labeled directed cycle is a directed cycle whose nonfixed arcs are labeled by progression states generating those arcs. If its required state literals are \(\ell_1,\dots,\ell_t\), then it yields the clause
\[
\neg\ell_1\vee\cdots\vee\neg\ell_t.
\]
The shell is satisfiable exactly when all such clauses are simultaneously satisfiable. This observation is important for descent: descending a single directed cycle chosen under one orientation is not enough. Unsatisfiability concerns a family of cycle clauses covering every orientation.

### 2. Consecutive progressions force alternating states

#### Lemma 1: Four-term alternation

If
\[
q,\ q+d,\ q+2d,\ q+3d\in X,
\]
then every acyclic orientation must assign opposite states to
\[
(q,q+d,q+2d)
\quad\text{and}\quad
(q+d,q+2d,q+3d).
\]

#### Proof

The first progression has midpoint \(q+d\), while the second has midpoint \(q+2d\).

If both are sources, they respectively add
\[
q+d\to q+2d
\quad\text{and}\quad
q+2d\to q+d,
\]
forming a directed \(2\)-cycle.

If both are sinks, the same two opposite arcs are again added. Therefore their states must differ. ∎

This accounts for every possible directed \(2\)-cycle generated by two internal progression choices. For a pair \(u<v\), an internal arc between them can only arise from

- the progression centered at \(u\), with upper endpoint \(v\), or
- the progression centered at \(v\), with lower endpoint \(u\).

When both exist, they are precisely the two consecutive windows in the four-term progression
\[
2u-v,\ u,\ v,\ 2v-u.
\]

#### Corollary 2: Arithmetic-line phase reduction

Fix \(d\). The possible centers form the interval
\[
B_d=[M+d,3M-1-d].
\]
Join two centers when they differ by \(d\). Every connected component is a path, and the states along it must alternate. Consequently, one binary phase determines all states in each component.

Conversely, imposing an alternating phase on every such component eliminates every internal-internal directed \(2\)-cycle. Since every acyclic orientation necessarily has these phases, the shell problem is exactly equivalent to finding phases whose full directed graph is acyclic.

The number of phase variables is
\[
\sum_{d=1}^{M-1}\min(d,2M-2d).
\]
Because \(3\mid M\), let \(h=2M/3\). Then
\[
\begin{aligned}
\sum_{d=1}^{M-1}\min(d,2M-2d)
&=\sum_{d=1}^{h}d
  +\sum_{d=h+1}^{M-1}2(M-d)\\
&=\frac{h(h+1)}2
  +2\sum_{e=1}^{M/3-1}e\\
&=\left(\frac{2M^2}{9}+\frac M3\right)
  +\left(\frac{M^2}{9}-\frac M3\right)\\
&=\frac{M^2}{3}.
\end{aligned}
\]

Thus the \(M(M-1)\) progression-state variables compress exactly to \(M^2/3\) phase variables.

This is a genuine reduction, but it does not control cycles of length at least \(3\).

### 3. Orientations forced by incoming edges

Let
\[
x\in U_k,\qquad y,z\in X,\qquad x<y<z,\qquad x+z=2y.
\]
Set
\[
d=y-x=z-y,
\]
so \(z=x+2d\). The incoming constraint is
\[
z\to y.
\]

For \(k\geq2\),
\[
x\leq \frac M3-1,\qquad y\geq M,
\]
and hence
\[
d=y-x\geq \frac{2M}{3}+1.
\]

#### Lemma 3: Exact immediate forcing

Suppose
\[
w=z+d=x+3d\leq 3M-1.
\]
Then the internal progression
\[
(y,z,w)
\]
is forced to have midpoint \(z\) as a source:
\[
z\to y,\qquad z\to w.
\]

#### Proof

If \((y,z,w)\) were assigned the sink state, it would add \(y\to z\), while the incoming edge already gives \(z\to y\). This would be a directed \(2\)-cycle. Therefore only the source state is possible. ∎

These forced progressions are isolated in their fixed-\(d\) arithmetic-line components. Indeed,
\[
x+4d=4y-3x
\geq 4M-3\left(\frac M3-1\right)
=3M+3,
\]
so the next progression
\[
(z,w,x+4d)
\]
is not internal. The preceding progression \((x,y,z)\) is not internal because \(x\notin X\).

#### Lemma 4: The fixed-edge \(2\)-cycle closure is consistent and acyclic

Start with all incoming edges. Force the source state in every progression described by Lemma 3. No further progression state is forced through a directed \(2\)-cycle, and the graph consisting of these fixed and forced arcs is acyclic.

#### Proof

For an incoming pair \(y<z\), a reverse internal arc \(y\to z\) could only be generated in one of two ways:

1. \(y\) is the midpoint and \(z\) an endpoint. The other endpoint is
   \[
   2y-z=x\notin X,
   \]
   so this is not an internal progression.
2. \(z\) is the midpoint and \(y\) an endpoint. The other endpoint is \(w=2z-y\), giving exactly the progression in Lemma 3 when \(w\in X\).

For a newly forced arc \(z\to w\), the only progression that could generate its reverse with \(w\) as midpoint would need upper endpoint
\[
2w-z=x+4d>3M-1.
\]
Thus there is no further internal forcing.

All incoming arcs go from the high region
\[
z\geq \frac{5M}{3}+1
\]
to the low region
\[
y\leq \frac{5M}{3}-1.
\]
Every additional forced arc has the form \(z\to w\) with \(w>z\), both in the high region. Hence a directed path either strictly increases while remaining in the high region, or eventually takes an incoming edge to the low region, where this forced subgraph has no outgoing arcs. A directed cycle is impossible. ∎

Therefore no obstruction is visible through incoming/internal directed \(2\)-cycles. Any shell obstruction must use a longer directed cycle and interactions between different common differences.

The number of forced source progressions can also be written explicitly. For fixed \(x\in U_k\), the allowed \(y\) satisfy
\[
M\leq y\leq
\left\lfloor\frac{3M-1+2x}{3}\right\rfloor,
\]
so their number is
\[
\left\lfloor\frac{2x-1}{3}\right\rfloor+1.
\]

### 4. Exact behavior under ternary projection

For \(r\in\{0,1,2\}\), define
\[
C_{k,r}=\{n\in X_k:n\equiv r\pmod 3\}
\]
and
\[
\phi_r(3q+r)=q.
\]
This maps \(C_{k,r}\) bijectively onto
\[
X_{k-1}=[3^{k-1},3^k-1].
\]

If an internal progression has common difference divisible by \(3\), all three values lie in one \(C_{k,r}\), and \(\phi_r\) maps it to an internal progression in \(X_{k-1}\).

For incoming edges lying entirely in one residue child, write
\[
x=3x'+r,\qquad y=3y'+r,\qquad z=3z'+r.
\]
Then
\[
x'=2y'-z'.
\]

For every old shell \(I_j\) with \(j\geq1\), the residue-\(r\) slice maps bijectively onto \(I_{j-1}\). Consequently:

- if \(k\) is odd, the incoming edges inside each child project exactly to \(E_{k-1}\);
- if \(k\) is even, the same holds except that:
  - the \(r=1\) child receives extra edges arising from \(x=1\);
  - the \(r=2\) child receives extra edges arising from \(x=2\);
  - after projection, these are the boundary edges
    \[
    2y'\to y',
    \]
    corresponding to the formal old value \(x'=0\).

Thus even the same-residue part is not closed under a single shell state: an additional \(x=0\) boundary state recurs at even levels. More seriously, progressions with common difference not divisible by \(3\) cross all three residue children and do not generally project to progressions.

### 5. A phase-consistent cycle that does not descend

Inside
\[
X_2=[9,26],
\]
choose the following three source states:
\[
(9,10,11),\qquad (9,11,13),\qquad (10,13,16).
\]
They add the arcs
\[
10\to11,\qquad 11\to13,\qquad 13\to10,
\]
which form a directed \(3\)-cycle.

These choices are compatible with all four-term alternation equations: their common differences are \(1,2,3\), so they belong to three independent phase families. Each specified state can be extended to an alternating phase on its own arithmetic-line component.

Under \(n\mapsto\lfloor n/3\rfloor\), the cycle vertices map as
\[
10\mapsto3,\qquad 11\mapsto3,\qquad 13\mapsto4.
\]
The directed cycle collapses rather than producing a smaller directed cycle.

This does not prove a shell unsatisfiable—the phases can be changed. It does rigorously disprove the naive descent assertion that every shortest phase-consistent directed cycle projects to a smaller cycle.

A successful descent would have to act on an unavoidable family of cycle clauses, not on an individual minimal cycle.

### 6. Failure of a natural quotient-parity orientation

The phase reduction suggests the uniform rule
\[
s_{b,d}=1
\quad\Longleftrightarrow\quad
\left\lfloor\frac bd\right\rfloor\ \text{is even}.
\]

This rule has two attractive properties.

First,
\[
\left\lfloor\frac{b+d}{d}\right\rfloor
=
\left\lfloor\frac bd\right\rfloor+1,
\]
so consecutive progression states alternate as required.

Second, for a forced incoming continuation, \(z=x+2d\) and \(0<x<d\), hence
\[
\left\lfloor\frac zd\right\rfloor=2.
\]
Thus every progression forced by Lemma 3 is assigned the required source state. The conceptual progression \((x,y,z)\) itself has
\[
\left\lfloor\frac yd\right\rfloor=1,
\]
so its sink state would indeed include \(z\to y\).

Nevertheless, the rule is cyclic already in
\[
X_3=[27,80].
\]
Consider
\[
(30,36,42),\qquad
(30,43,56),\qquad
(29,36,43).
\]
The states are:

- \(36/6=6\), even, so \(36\) is a source and
  \[
  36\to30;
  \]
- \(\lfloor43/13\rfloor=3\), odd, so \(43\) is a sink and
  \[
  30\to43;
  \]
- \(\lfloor36/7\rfloor=5\), odd, so \(36\) is a sink and
  \[
  43\to36.
  \]

Hence
\[
36\to30\to43\to36
\]
is a directed \(3\)-cycle. This kills the most natural explicit phase assignment arising from the incoming geometry.

### 7. Failure of the coarse “all high values first” order

For \(k=2\), all incoming edges go from
\[
[16,26]
\]
toward \([9,14]\). It is tempting to put all of \([16,26]\) before all of \([9,15]\). This is impossible even before considering the exact incoming edge set.

Assume every value in \([16,26]\) precedes every value in \([9,15]\).

From the progression \((14,15,16)\), since \(16\) precedes both lower values, non-betweenness forces
\[
14\to15.
\]
Similarly:

- \((13,15,17)\) forces \(13\to15\);
- \((11,14,17)\) forces \(11\to14\).

Now in \((13,14,15)\), the relation \(14\to15\) rules out making \(14\) a sink, so \(14\) must be a source:
\[
14\to13.
\]
In \((11,13,15)\), the relation \(13\to15\) similarly forces
\[
13\to11.
\]
Thus
\[
11\to14\to13\to11,
\]
a contradiction.

Therefore any successful shell order must genuinely interleave parts of the high and low regions; the one-way geometry of \(E_k\) cannot be implemented by a single coarse cut.

## Self-Audit

1. **The phase reduction controls only directed \(2\)-cycles.**  
   It does not establish that some phase assignment avoids all longer cycles. I believe the reduction itself is exact because every possible internal-internal reverse pair comes from two consecutive windows of one four-term progression, but the remaining \(M^2/3\)-variable acyclicity problem is still substantial.

2. **The forced-orientation closure is deliberately limited to consequences detectable through a reverse arc.**  
   Longer cycle clauses may force additional states globally, so Lemma 4 is not a full propagation theorem. Its stated scope is nevertheless exact: the uniqueness of the third point for a midpoint-endpoint pair and the bound \(x+4d>3M-1\) exhaust all immediate reverse-arc possibilities.

3. **The ternary projection has an exceptional \(x'=0\) boundary state.**  
   This indexing is easy to mishandle. It follows directly from \(I_0=\{1,2\}\): when \(k\) is even, \(I_0\subset U_k\), and its residue-\(1\) and residue-\(2\) elements project to \(0\). A finite generator should verify this identity for several \(k\).

## Computations To Verify

The following phase-compressed CP-SAT model is exact. It should be run for \(k=2,3,4,5,6\).

```python
from collections import defaultdict
from ortools.sat.python import cp_model

def shell_data(k):
    M = 3 ** k
    X = list(range(M, 3*M))

    U = set()
    for j in range(max(0, k-1)):       # j = 0,...,k-2
        if (j - k) % 2 == 0:
            U.update(range(3**j, 3**(j+1)))

    aps = []
    for d in range(1, M):
        for b in range(M+d, 3*M-d):
            aps.append((b-d, b, b+d, d))

    edges = []
    for x in sorted(U):
        ymax = (3*M - 1 + x) // 2
        for y in range(M, ymax + 1):
            z = 2*y - x
            assert y < z <= 3*M - 1
            edges.append((z, y))

    return M, X, U, aps, sorted(set(edges))


def phase_structure(M):
    """
    Returns:
      groups[(d,r)] = sorted centers in one d-line component,
      info[(b,d)] = ((d,r), parity index in that component).
    """
    groups = defaultdict(list)
    for d in range(1, M):
        for b in range(M+d, 3*M-d):
            groups[(d, b % d)].append(b)

    info = {}
    for key, centers in groups.items():
        centers.sort()
        d, _ = key
        b0 = centers[0]
        for b in centers:
            j = (b - b0) // d
            assert b == b0 + j*d
            info[(b, d)] = (key, j & 1)

    return groups, info


def solve_phase_model(k, time_limit=3600):
    M, X, U, aps, edges = shell_data(k)
    groups, info = phase_structure(M)

    if k >= 1:
        assert len(groups) == M*M // 3, (k, len(groups), M*M//3)

    model = cp_model.CpModel()

    phase = {
        key: model.NewBoolVar(f"phase_d{key[0]}_r{key[1]}")
        for key in groups
    }
    height = {
        v: model.NewIntVar(0, len(X)-1, f"h_{v}")
        for v in X
    }

    for z, y in edges:
        model.Add(height[z] + 1 <= height[y])

    for a, b, c, d in aps:
        key, parity = info[(b, d)]
        src = phase[key] if parity == 0 else phase[key].Not()

        model.Add(height[b] + 1 <= height[a]).OnlyEnforceIf(src)
        model.Add(height[b] + 1 <= height[c]).OnlyEnforceIf(src)

        model.Add(height[a] + 1 <= height[b]).OnlyEnforceIf(src.Not())
        model.Add(height[c] + 1 <= height[b]).OnlyEnforceIf(src.Not())

    # Optional explicit propagation of Lemma 3.
    for x in U:
        ymax = (3*M - 1 + x) // 2
        for y in range(M, ymax + 1):
            d = y - x
            z = y + d
            w = z + d
            if w <= 3*M - 1:
                key, parity = info[(z, d)]
                if parity == 0:
                    model.Add(phase[key] == 1)
                else:
                    model.Add(phase[key] == 0)

    solver = cp_model.CpSolver()
    solver.parameters.max_time_in_seconds = time_limit
    solver.parameters.num_search_workers = 8
    status = solver.Solve(model)

    print("k =", k,
          "M =", M,
          "vertices =", len(X),
          "APs =", len(aps),
          "incoming =", len(edges),
          "phases =", len(groups),
          "status =", solver.StatusName(status))

    if status not in (cp_model.OPTIMAL, cp_model.FEASIBLE):
        return None

    # Ties are harmless because every constrained arc has strict heights.
    order = sorted(X, key=lambda v: (solver.Value(height[v]), v))
    return order


def check_order(k, order):
    M, X, U, aps, edges = shell_data(k)
    assert len(order) == len(X)
    assert set(order) == set(X)

    pos = {v: i for i, v in enumerate(order)}
    assert len(pos) == len(X)

    for z, y in edges:
        assert pos[z] < pos[y], (z, y)

    for a, b, c, d in aps:
        assert (
            pos[b] < min(pos[a], pos[c])
            or
            pos[b] > max(pos[a], pos[c])
        ), (a, b, c)

    return True


for k in range(2, 7):
    witness = solve_phase_model(k)
    if witness is not None:
        assert check_order(k, witness)
        print("witness prefix:", witness[:30])
```

## Route Diagnosis

**Proved ledger**

- The shell problem is exactly an acyclic source/sink orientation problem.
- Consecutive \(3\)-AP windows in every \(4\)-AP must have opposite states.
- This gives an exact reduction to \(M^2/3\) arithmetic-line phase variables.
- All progression states immediately forced by incoming edges were identified.
- Those forced states are isolated phase variables, and their forced graph is acyclic.
- Same-residue ternary projection is exact up to recurring \(x'=0\) boundary edges.
- A phase-consistent directed \(3\)-cycle can collapse under ternary projection.
- The quotient-parity phase rule, despite satisfying alternation and all local incoming forcing, fails in \(I_3\).
- A coarse high-before-low shell order already fails in \(I_2\).

**Plausible but unproved**

- Every ternary shell may still possess a suitable phase assignment.
- Minimal unsatisfiable cycle-clause cores, if any, may have a finite residue-pattern classification.
- A descent might work on entire minimal UNSAT cores rather than individual cycles.

**Dead ends**

- Descending arbitrary shortest directed cycles under \(n\mapsto\lfloor n/3\rfloor\): false, because cross-residue cycles can collapse.
- Orienting by \(\lfloor b/d\rfloor\bmod2\): explicit directed \(3\)-cycle in \([27,80]\).
- Satisfying all incoming edges by placing the entire upper region first: explicit contradiction in \([9,26]\).
- Treating the fixed-edge \(2\)-cycle closure as sufficient: it is acyclic, but longer mixed-difference cycles remain.

The precise block is now this:

> Choose one phase for each of the \(M^2/3\) arithmetic-line components so that the resulting graph, together with \(E_k\), has no directed cycle of length at least \(3\), uniformly for every \(M=3^k\).

This remains an unproved statement of essentially shell-level strength, so Route 2 is BLOCKED. A fresh attempt should use the phase-compressed solver, extract minimal phase-level cycle cores, and classify cross-residue triangles and longer cycles. Any viable descent must transform an entire unavoidable cycle-clause core and must carry the recurring \(x'=0\) boundary state; projection of a single selected cycle cannot suffice.
