## Result

I obtained an exact finite-state formulation of Route 2. For each prime \(p\), its behavior across the \(\ell\)-rows is a single deterministic “track,” parameterized by an activity phase \(\rho_p\) and an initial \(k\)-intercept \(\alpha_p\). This yields: (i) an exact template-cycle criterion; (ii) a rigorous row-capacity LP dual giving target-independent obstructions; and (iii) stronger rowwise overlap bounds using forests of forced intersections. As a concrete application, the 30-prime low-index pool displayed in the brief cannot contain a cover: iterative cohort pruning leaves 15 primes of total mass \(6503/7200<1\). No covering certificate, and hence no solution to Erdős problem #203, was found.

## Complete Argument

### 1. Exact normal form for a prime’s row orbit

Fix a prime \(p\ge 5\), and write

\[
d_p=\operatorname{ord}_p(2),\qquad
e_p=\operatorname{ord}_p(3),\qquad
h_p=\operatorname{lcm}(d_p,e_p).
\]

Let

\[
A_p=\langle 2\rangle\le H_p=\langle2,3\rangle.
\]

Since \(|A_p|=d_p\) and \(|H_p|=h_p\), define

\[
s_p=[H_p:A_p]=\frac{h_p}{d_p}.
\]

The quotient \(H_p/A_p\) is generated by the image of \(3\), so that image has order exactly \(s_p\). Consequently,

\[
3^{s_p}\in \langle2\rangle.
\]

There is therefore a unique \(v_p\pmod{d_p}\) satisfying

\[
3^{s_p}\equiv 2^{v_p}\pmod p.
\]

#### Lemma 1: target normal form

Every \(t\in H_p\) has a unique representation

\[
t=3^\rho 2^\alpha
\]

with

\[
0\le \rho<s_p,\qquad 0\le \alpha<d_p.
\]

For this target,

\[
2^k3^\ell\equiv t\pmod p
\]

holds exactly on the rows

\[
\ell\equiv \rho\pmod{s_p}.
\]

Writing \(\ell=\rho+s_p n\), the covered \(k\)-class is

\[
k\equiv \alpha-v_pn\pmod{d_p}.
\]

#### Proof

Existence follows from the fact that the cosets

\[
A_p,3A_p,\ldots,3^{s_p-1}A_p
\]

are all the cosets of \(A_p\) in \(H_p\). Thus \(t\in3^\rho A_p\) for some \(\rho\), and then \(t=3^\rho2^\alpha\).

If

\[
3^\rho2^\alpha=3^{\rho'}2^{\alpha'}
\]

with \(0\le\rho,\rho'<s_p\), then \(3^{\rho-\rho'}\in A_p\). The order of \(3A_p\) in \(H_p/A_p\) is \(s_p\), so \(\rho\equiv\rho'\pmod{s_p}\), hence \(\rho=\rho'\). It follows that \(2^\alpha=2^{\alpha'}\), and therefore \(\alpha\equiv\alpha'\pmod{d_p}\).

Now

\[
2^k3^\ell=t
\]

implies \(3^{\ell-\rho}\in A_p\), which is equivalent to \(s_p\mid\ell-\rho\). If \(\ell=\rho+s_pn\), then

\[
2^k3^\ell
 =2^k3^\rho(3^{s_p})^n
 =3^\rho2^{k+v_pn}.
\]

By uniqueness of the representation,

\[
k+v_pn\equiv\alpha\pmod{d_p}.
\]

This proves the formula. ∎

Thus a prime does not provide independently selectable classes on different rows. It provides one deterministic track

\[
T_p(\rho,\alpha)=
\left\{(k,\ell):
\ell=\rho+s_pn,\quad
k\equiv\alpha-v_pn\pmod{d_p}\right\}.
\]

There are exactly \(s_pd_p=h_p\) possible tracks, agreeing with the \(h_p\) target cosets.

For example:

\[
\begin{array}{c|c|c|c}
p&d_p&s_p&v_p\\ \hline
7&3&2&1\\
17&8&2&7\\
31&5&6&4\\
73&9&4&3
\end{array}
\]

Indeed,

\[
3^2\equiv2\pmod7,\quad
3^2\equiv2^7\pmod{17},\quad
3^6\equiv2^4\pmod{31},\quad
3^4\equiv2^3\pmod{73}.
\]

These small cases also provide direct checks against sign or transition errors in the formula.

### 2. Exact finite-cycle criterion

Let \(\mathcal P\) be a finite prime pool. Set

\[
A=\operatorname{lcm}_{p\in\mathcal P} d_p,\qquad
B=\operatorname{lcm}_{p\in\mathcal P} e_p.
\]

Because \(s_p\mid e_p\), every track is periodic on

\[
G=\mathbb Z/A\mathbb Z\times\mathbb Z/B\mathbb Z.
\]

The transition is well-defined modulo \(B\): since \(3^B=1\pmod p\),

\[
2^{v_pB/s_p}=(3^{s_p})^{B/s_p}=3^B=1,
\]

so

\[
d_p\mid v_pB/s_p.
\]

#### Theorem 2: finite-state template criterion

A choice of one target \(t_p\in H_p\) for each selected prime covers \(\mathbb Z^2\) if and only if one can select one pair

\[
(\rho_p,\alpha_p)\in
\mathbb Z/s_p\mathbb Z\times\mathbb Z/d_p\mathbb Z
\]

for each selected \(p\), such that for every \(\ell\pmod B\), the one-dimensional residue classes

\[
k\equiv
\alpha_p-v_p\frac{\ell-\rho_p}{s_p}
\pmod{d_p},
\qquad
p\text{ with }\ell\equiv\rho_p\pmod{s_p},
\]

cover every \(k\pmod A\).

#### Proof

By Lemma 1, the selected target \(t_p=3^{\rho_p}2^{\alpha_p}\) covers exactly the displayed class on row \(\ell\). Therefore the global union covers precisely when the active one-dimensional classes cover every row.

Periodicity modulo \(A\) and \(B\) shows that checking all rows and all \(k\) is equivalent to checking \(G\). ∎

This is the precise version of the proposed “finite cycle of Sierpiński templates.” A row template cannot be selected independently: a prime active on row \(\rho_p+s_pn\) must move by \(-v_p\) modulo \(d_p\) every \(s_p\) row steps.

### 3. Row-capacity obstruction and its exact fractional dual

Let

\[
S=\operatorname{lcm}_{p\in\mathcal P}s_p.
\]

For a selected phase \(\rho_p\), prime \(p\) is active exactly on rows

\[
r\equiv\rho_p\pmod{s_p},
\]

and on each active row it covers density \(1/d_p\) of the \(k\)-axis.

#### Theorem 3: weighted row-capacity inequality

If the pool admits a cover, then for every choice of nonnegative real row weights

\[
y_r\ge0,\qquad r\in\mathbb Z/S\mathbb Z,
\]

one necessarily has

\[
\boxed{
\sum_{r\bmod S}y_r
\le
\sum_{p\in\mathcal P}
\frac1{d_p}
\max_{\rho\bmod{s_p}}
\sum_{\substack{r\bmod S\\r\equiv\rho\;(\mathrm{mod}\ s_p)}}y_r.
}
\tag{1}
\]

#### Proof

Fix an actual target assignment. On each row \(r\), the active residue classes must cover \(\mathbb Z\), so the union bound gives

\[
1\le
\sum_{\substack{p\\r\equiv\rho_p\;(\mathrm{mod}\ s_p)}}\frac1{d_p}.
\]

Multiply by \(y_r\) and sum over \(r\):

\[
\sum_r y_r
\le
\sum_p\frac1{d_p}
\sum_{\substack{r\\r\equiv\rho_p\;(\mathrm{mod}\ s_p)}}y_r.
\]

For each \(p\), the last sum is bounded by the maximum over all possible phases \(\rho\). This proves (1). ∎

The uniform choice \(y_r=1\) recovers

\[
1\le\sum_p\frac1{s_pd_p}
=\sum_p\frac1{h_p}.
\]

Taking \(y\) supported on one row gives the additional necessary condition

\[
1\le\sum_p\frac1{d_p},
\]

where every prime is hypothetically allowed to place its active phase on that row.

More generally, for every subset \(R\subseteq\mathbb Z/S\mathbb Z\),

\[
|R|
\le
\sum_p\frac1{d_p}
\max_{\rho\bmod s_p}
\left|R\cap\{r:r\equiv\rho\pmod{s_p}\}\right|.
\tag{2}
\]

#### Exact LP interpretation

Introduce fractional phase variables

\[
x_{p,\rho}\ge0,\qquad
\sum_{\rho\bmod s_p}x_{p,\rho}=1.
\]

The fractional row scheduler asks for

\[
\sum_p\frac{x_{p,r\bmod s_p}}{d_p}\ge1
\qquad(r\bmod S).
\tag{3}
\]

Inequality (1) for every \(y\ge0\) is necessary and sufficient for feasibility of this fractional relaxation.

To see this, the possible capacity vectors form the compact convex set

\[
C=\left\{
\left(
\sum_p\frac{x_{p,r\bmod s_p}}{d_p}
\right)_{r\bmod S}
\right\}.
\]

The system is feasible exactly when \(C\) intersects the upper orthant

\[
U=\{z:z_r\ge1\}.
\]

If \(C\cap U=\varnothing\), strict separation gives a linear functional \(y\). Its infimum on \(U\) is finite only when \(y\ge0\), and then

\[
\inf_{z\in U}y\cdot z=\sum_r y_r.
\]

On the other hand,

\[
\sup_{c\in C}y\cdot c
=
\sum_p\frac1{d_p}
\max_{\rho\bmod s_p}
\sum_{r\equiv\rho\;(\mathrm{mod}\ s_p)}y_r.
\]

Thus separation is precisely a violation of (1).

This is only a fractional phase test. It does not choose an integral phase, does not select intercepts \(\alpha_p\), and does not prove that the \(k\)-classes cover.

### 4. Full weighted target obstruction

The row-capacity test can be strengthened without yet solving the integer covering problem.

On the torus

\[
G=\mathbb Z/A\mathbb Z\times\mathbb Z/B\mathbb Z,
\]

let \(w(k,\ell)\ge0\) be arbitrary. If one track per prime covers \(G\), then

\[
\boxed{
\sum_{(k,\ell)\in G}w(k,\ell)
\le
\sum_{p\in\mathcal P}
\max_{\substack{\rho\bmod s_p\\\alpha\bmod d_p}}
\sum_{(k,\ell)\in T_p(\rho,\alpha)}w(k,\ell).
}
\tag{4}
\]

Indeed, pointwise coverage gives

\[
1_G\le\sum_p1_{T_p(\rho_p,\alpha_p)}.
\]

Multiplication by \(w\), summation, and separate maximization over each prime prove (4).

As with Theorem 3, all inequalities (4) are exactly the dual obstructions to the fractional relaxation in which each prime may be fractionally distributed among its \(h_p\) tracks. A rational \(w\) violating (4) is therefore a short, exact no-cover certificate for a proposed pool.

### 5. Rowwise forced-overlap bounds

Density alone can be too weak because residue classes on a row may be forced to overlap.

#### Lemma 4: forest overlap inequality

Let \(E_1,\ldots,E_n\) be subsets of a finite probability space, and let \(F\) be any forest on vertices \(1,\ldots,n\). Then

\[
\mu\left(\bigcup_iE_i\right)
\le
\sum_i\mu(E_i)
-\sum_{\{i,j\}\in E(F)}\mu(E_i\cap E_j).
\tag{5}
\]

#### Proof

For a point \(x\), let \(V_x=\{i:x\in E_i\}\). The subgraph of a forest induced by \(V_x\) has at most \(|V_x|-1\) edges when \(V_x\ne\varnothing\). Hence pointwise,

\[
1_{\cup E_i}(x)
\le
\sum_i1_{E_i}(x)
-\sum_{\{i,j\}\in E(F)}1_{E_i\cap E_j}(x).
\]

Summing or integrating proves (5). ∎

On a fixed row, two residue classes modulo \(d_i,d_j\) necessarily intersect whenever

\[
\gcd(d_i,d_j)=1.
\]

Their intersection then has density

\[
\frac1{d_id_j}.
\]

Consequently, if \(F\) is any forest whose edges join active primes with coprime \(2\)-orders, row coverage requires

\[
1\le
\sum_{\text{active }p}\frac1{d_p}
-
\sum_{\{p,q\}\in E(F)}\frac1{d_pd_q}.
\tag{6}
\]

This is target-independent: coprime moduli cannot be made disjoint by choosing different intercepts.

For two always-active primes, there is also an exact criterion without assuming coprime orders. Their classes have the form

\[
k\equiv\alpha_i-v_i\ell\pmod{d_i},\qquad
k\equiv\alpha_j-v_j\ell\pmod{d_j}.
\]

Writing \(g=\gcd(d_i,d_j)\), they intersect on row \(\ell\) exactly when

\[
(v_i-v_j)\ell
\equiv
\alpha_i-\alpha_j
\pmod g.
\tag{7}
\]

Thus the rows of intersection, and the density lost on those rows, can be computed exactly. In particular, if \(g=1\), they intersect on every row with density \(1/(d_id_j)\).

This rules out treating row mass \(W_r\ge1\) as sufficient.

### 6. A finite pool eliminated exactly

Consider the 30 primes listed in the brief’s order table:

\[
\begin{aligned}
\mathcal P_{30}=\{&
5,7,11,23,13,17,19,47,29,31,71,37,73,41,43,431,\\
&97,53,59,61,67,601,79,83,167,89,191,193,101,103\}.
\end{aligned}
\]

I now prove that no selection of targets from this pool can cover \(\mathbb Z^2\).

#### Cohort lemma, with proof

Let finite cosets \(a_i+H_i\) cover a finite abelian group \(G\) inclusion-minimally. If a prime \(q\) divides \([G:H_i]\) for one selected set, then at least \(q\) selected subgroup indices are divisible by \(q\).

To prove this, choose a point \(x\) covered only by \(a_i+H_i\), which exists by inclusion-minimality. Let \(Q\) be the Sylow \(q\)-subgroup of \(G\), and consider the fiber \(x+Q\).

If \(q\nmid[G:H_j]\), then \(Q\subseteq H_j\). Hence \(a_j+H_j\) either contains all of \(x+Q\) or none of it. It cannot contain all of it because it does not contain \(x\). Therefore all of \(x+Q\) must be covered by sets whose indices are divisible by \(q\).

Each such set meets \(x+Q\), if at all, in a coset of a proper subgroup of \(Q\). A proper subgroup of the finite \(q\)-group \(Q\) has size at most \(|Q|/q\). Fewer than \(q\) such cosets have union of size less than \(|Q|\). Thus at least \(q\) selected indices are divisible by \(q\). ∎

This permits iterative pruning: if fewer than \(q\) candidates in the current pool have \(q\mid h_p\), none of them can occur in an inclusion-minimal cover.

For \(\mathcal P_{30}\), the following candidates are removed:

\[
\begin{array}{c|l}
q&\text{candidates removed}\\ \hline
7&29,\ 71,\ 43\\
11&23,\ 67,\ 89\\
13&53,\ 79\\
17&103\\
19&191\\
23&47\\
29&59\\
41&83\\
43&431\\
83&167
\end{array}
\]

After these deletions, the surviving primes are

\[
\mathcal P_{\mathrm{surv}}
=
\{5,7,11,13,17,19,31,37,73,41,97,61,601,193,101\}.
\]

Their indices are respectively

\[
4,6,10,12,16,18,30,36,36,40,48,60,75,96,100.
\]

No further cohort deletion is forced: six surviving indices are divisible by \(5\), ten by \(3\), and sufficiently many by \(2\).

Their total mass is

\[
\begin{aligned}
\sum_{p\in\mathcal P_{\mathrm{surv}}}\frac1{h_p}
&=
\frac14+\frac16+\frac1{10}+\frac1{12}+\frac1{16}
+\frac1{18}+\frac1{30}
+\frac2{36}+\frac1{40}\\
&\qquad+\frac1{48}+\frac1{60}+\frac1{75}
+\frac1{96}+\frac1{100}\\
&=\frac{6503}{7200}<1.
\end{aligned}
\]

Suppose the original pool admitted a cover. Remove redundant sets to obtain an inclusion-minimal cover. The cohort argument shows that it can use none of the deleted candidates, so it is contained in \(\mathcal P_{\mathrm{surv}}\). But the necessary mass condition then fails. This contradiction proves:

\[
\boxed{\mathcal P_{30}\text{ cannot supply a finite cover.}}
\]

This eliminates only this finite pool, not the original Erdős problem.

### 7. Ledger

#### Proved

1. Every prime target has a unique row-track parameterization \((\rho_p,\alpha_p)\).
2. The transition law is
   \[
   \ell=\rho_p+s_pn
   \implies
   k\equiv\alpha_p-v_pn\pmod{d_p}.
   \]
3. Route 2 is exactly a finite cycle of one-dimensional covering systems subject to these transition laws.
4. The weighted row-capacity inequality (1) is necessary.
5. All row-capacity inequalities are equivalent to feasibility of the fractional phase scheduler.
6. The full weighted obstruction (4) is necessary and is the dual of the fractional track relaxation.
7. The forest overlap inequality (5) and its rowwise consequence (6).
8. The displayed 30-prime pool cannot contain a cover.

#### Plausible but unproved

1. A sufficiently large cohort-closed pool with small \(s_p=h_p/d_p\) may pass the phase LP and admit an integral track cover.
2. Pools dominated by \(s_p=1,2,3,4,6,8\) are likely the most computationally accessible Route 2 candidates.
3. Exact weighted dual cuts and lazy row-template generation may make a search below \(10^5\) feasible.

#### Dead ends

1. **Independent row templates:** invalid because one prime’s classes must obey the transition law.
2. **Row capacities alone:** insufficient because classes can overlap or leave residue gaps.
3. **The 30-prime low-index pool:** rigorously eliminated by cohort pruning followed by mass.
4. **A barely supercritical row:** vulnerable to unavoidable intersections such as coprime \(d_p\).

## Self-Audit

1. **No global certificate was obtained.**  
   The main weakness is decisive: none of the lemmas constructs \(m\) or excludes every possible \(m\). I therefore claim only partial progress. The finite-state reductions themselves are exact consequences of subgroup structure and do not depend on conjectures.

2. **The LP dual criteria are only fractional obstructions.**  
   Passing them would not imply an integral target assignment, much less exact row coverage. I have explicitly kept the direction one-way. The equivalence claimed is only between the weighted inequalities and the fractional relaxation, proved by finite-dimensional separation.

3. **The 30-prime elimination relies on iterative cohort pruning.**  
   A pruning argument would be unsafe without first passing to an inclusion-minimal cover. That step is included, and the cohort lemma is proved using a private point and the Sylow \(q\)-fiber. The final mass calculation is exact:
   \[
   6503/7200<1.
   \]

The following Python checks the local track data and the 30-prime pruning calculation.

```python
from math import gcd, lcm
from fractions import Fraction
from collections import Counter
from sympy import n_order, factorint

P30 = [
    5, 7, 11, 23, 13, 17, 19, 47, 29, 31,
    71, 37, 73, 41, 43, 431, 97, 53, 59, 61,
    67, 601, 79, 83, 167, 89, 191, 193, 101, 103
]

def local_data(p):
    d = int(n_order(2, p))
    e = int(n_order(3, p))
    h = lcm(d, e)
    s = h // d

    rhs = pow(3, s, p)
    vals = [v for v in range(d) if pow(2, v, p) == rhs]
    assert len(vals) == 1
    v = vals[0]

    # Every target 3^rho 2^alpha must be distinct.
    targets = {}
    for rho in range(s):
        for alpha in range(d):
            t = pow(3, rho, p) * pow(2, alpha, p) % p
            assert t not in targets
            targets[t] = (rho, alpha)
    assert len(targets) == h

    # Directly check the track formula over multiple periods.
    for t, (rho, alpha) in targets.items():
        for ell in range(3 * e):
            for k in range(3 * d):
                direct = (pow(2, k, p) * pow(3, ell, p) - t) % p == 0
                if (ell - rho) % s == 0:
                    n = (ell - rho) // s
                    track = (k - (alpha - v*n)) % d == 0
                else:
                    track = False
                assert direct == track

    return d, e, h, s, v

data = {p: local_data(p) for p in P30}

assert data[7]  == (3, 6, 6, 2, 1)
assert data[17] == (8, 16, 16, 2, 7)
assert data[31] == (5, 30, 30, 6, 4)
assert data[73] == (9, 12, 36, 4, 3)

def cohort_prune(primes):
    alive = set(primes)
    while True:
        counts = Counter()
        factors = {}
        for p in alive:
            h = data[p][2]
            factors[p] = set(factorint(h))
            for q in factors[p]:
                counts[q] += 1

        bad = {
            p for p in alive
            if any(counts[q] < q for q in factors[p])
        }
        if not bad:
            return sorted(alive)
        alive -= bad

survivors = cohort_prune(P30)
expected = sorted([
    5, 7, 11, 13, 17, 19, 31, 37, 73, 41,
    97, 61, 601, 193, 101
])
assert survivors == expected

mass = sum(Fraction(1, data[p][2]) for p in survivors)
assert mass == Fraction(6503, 7200)
assert mass < 1

print("Survivors:", survivors)
print("Mass:", mass, float(mass))
```

A row-capacity dual certificate can be checked exactly as follows. The vector `y` should first be discovered by an LP solver and then converted to rational numbers.

```python
def exact_row_cut(primes, y):
    """
    y: list of nonnegative Fractions.
    Its length must be divisible by every s_p.
    Returns (LHS, RHS); RHS < LHS certifies impossibility.
    """
    S = len(y)
    assert all(v >= 0 for v in y)

    lhs = sum(y, Fraction(0))
    rhs = Fraction(0)

    for p in primes:
        d, e, h, s, v = data[p]
        assert S % s == 0
        best = max(
            sum((y[r] for r in range(rho, S, s)), Fraction(0))
            for rho in range(s)
        )
        rhs += best / d

    return lhs, rhs
```

For a manageable candidate pool, the exact Route 2 covering ILP is:

```python
# Requires: pip install ortools
from ortools.sat.python import cp_model

def solve_track_cover(primes):
    A = 1
    B = 1
    for p in primes:
        d, e, h, s, v = data[p]
        A = lcm(A, d)
        B = lcm(B, e)

    model = cp_model.CpModel()
    x = {}

    for p in primes:
        d, e, h, s, v = data[p]
        for rho in range(s):
            for alpha in range(d):
                x[p, rho, alpha] = model.NewBoolVar(
                    f"x_{p}_{rho}_{alpha}"
                )

        # A prime may be omitted, but cannot have two targets.
        model.Add(sum(
            x[p, rho, alpha]
            for rho in range(s)
            for alpha in range(d)
        ) <= 1)

    for ell in range(B):
        for k in range(A):
            covering = []
            for p in primes:
                d, e, h, s, v = data[p]
                for rho in range(s):
                    if (ell - rho) % s:
                        continue
                    n = (ell - rho) // s
                    alpha = (k + v*n) % d
                    covering.append(x[p, rho, alpha])
            model.Add(sum(covering) >= 1)

    solver = cp_model.CpSolver()
    solver.parameters.num_search_workers = 8
    status = solver.Solve(model)

    if status not in (cp_model.OPTIMAL, cp_model.FEASIBLE):
        return None

    answer = {}
    for p in primes:
        d, e, h, s, v = data[p]
        for rho in range(s):
            for alpha in range(d):
                if solver.Value(x[p, rho, alpha]):
                    answer[p] = (rho, alpha)
    return A, B, answer
```

The rectangular ILP is practical only when \(AB\) is moderate. For larger pools, constraints should be generated lazily by searching for an uncovered row/class after each tentative target assignment.

## Route Diagnosis

Route 2 is structurally sound but not yet completed. Its main gain is that the relevant row-state complexity is governed by

\[
s_p=\frac{h_p}{o_{2,p}},
\]

not directly by \(h_p\) or \(o_{3,p}\). Primes with \(s_p=1\) are active on every row; primes with small \(s_p\) are controlled row-selective resources. This suggests prioritizing a cohort-closed pool with small \(s_p\), rather than another \(2\)-\(3\)-smooth-index pool.

The recommended next search is:

1. Enumerate primes, recording \((d_p,s_p,v_p)\).
2. Apply iterative cohort pruning.
3. Reject pools failing the exact row-phase LP.
4. Add forest-overlap cuts for coprime active \(d_p\).
5. Solve the fractional full-track LP and extract rational weighted obstructions when infeasible.
6. Only then run the integral track-cover search, using lazy uncovered-cell constraints.
7. If a cover is found, convert
   \[
   t_p=3^{\rho_p}2^{\alpha_p}
   \]
   to CRT conditions
   \[
   m\equiv-t_p^{-1}\pmod p.
   \]

The present block is combinatorial, not a reduction to a known prime-distribution conjecture: no cohort-closed finite pool has yet been shown either to admit or to forbid the required integral template cycle.
